# 📊 Practical 1: Data Analysis Fundamentals, Data Acquisition, Data Cleaning & EDA

## 📖 Overview

This practical introduces the fundamentals of **Data Analysis** and **Data Science**. It covers the complete data analysis workflow, including data acquisition, data cleaning, exploratory data analysis (EDA), and data profiling using Python libraries such as **Pandas**, **NumPy**, **Matplotlib**, and **SQLite**.

---

## 🎯 Objectives

- Understand the basics of Data Analysis.
- Learn the Data Science project lifecycle.
- Define a Machine Learning problem statement.
- Understand tensors with NumPy examples.
- Import data from multiple sources.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Generate a data profiling report.

---

## 🛠 Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- SQLite
- JSON
- Requests (API)

## 📂 Dataset

**Dataset Name:** Customer Shopping Dataset

The dataset contains customer information such as:

- Customer ID
- Name
- Gender
- Age

- Purchases
- Churn
- City

The dataset is used to demonstrate data acquisition, cleaning, visualization, and profiling techniques.
